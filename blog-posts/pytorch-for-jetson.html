Jetson Cihazları İçin PyTorch Ortam Kurulumu

Bu rehberde, NVIDIA Jetson Xavier NX üzerinde GPU hızlandırma destekli PyTorch ve Torchvision kütüphanelerinin kurulum adımları detaylandırılmıştır. Dokümantasyon, diğer Jetson modelleri (Nano, Orin vb.) için de uyarlanabilir yapıdadır.

Sistem Gereksinimleri ve Kontrol

Aşağıdaki görselde kullandığımız Jetson Xavier NX cihazına ait sistem özellikleri yer almaktadır. Kendi cihazınızın donanım ve JetPack uyumluluğunu terminal üzerinden doğrulayabilirsiniz.

Sanal Ortam (VENV) Yapılandırması

Farklı projelerde bağımlılık çakışmalarını önlemek ve sistem kütüphanelerini izole etmek adına, global kurulum yerine sanal ortam (virtual environment) kullanılması şiddetle tavsiye edilir.

$python3 -m venv venv_adi
$source venv_adi/bin/activate

Sistem Bağımlılıkları ve Kurulum

Derleme (build) süreçlerinin sorunsuz tamamlanabilmesi için öncelikle temel sistem bağımlılıklarının kurulması gerekmektedir.

$sudo apt-get -y update
$sudo apt-get -y install python3-pip libopenblas-dev

Kurulum sürecini hızlandırmak adına cihaz spesifikasyonlarına uygun derlenmiş (pre-built) wheel dosyaları hazırlanmıştır. Aşağıdaki bağlantıdan indirerek doğrudan kuruluma geçebilirsiniz.

PyTorch & Torchvision Wheel (.whl) İndir 
$pip install torch_wheel_adi.whl
$pip install torchvision_wheel_adi.whl

Kurulumun doğruluğunu ve kütüphane versiyonlarını test etmek için aşağıdaki Python betiğini çalıştırabilirsiniz:

import torch
import torchvision

print(f"PyTorch Version: {torch.__version__}")
print(f"Torchvision Version: {torchvision.__version__}")
print(f"CUDA Available: {torch.cuda.is_available()}")

Farklı Jetson Modellerine Uyarlama

Eğer farklı bir JetPack sürümü kullanıyorsanız, ilgili Torch wheel dosyasını doğrudan NVIDIA Resmi Dokümantasyonu üzerinden temin edebilirsiniz. Unutulmamalıdır ki Torchvision derlenmeden önce PyTorch sistemde kurulu olmalıdır.

$pip install torch_wheel_adi.whl

Torchvision kütüphanesini sisteminiz için kaynak koddan (source) derlemek istiyorsanız aşağıdaki adımları izleyebilirsiniz:

$git clone https://github.com/pytorch/vision.git
$cd torchvision
$sudo apt update
$sudo apt install -y python3-dev python3-pip libjpeg-dev libpng-dev
$pip3 install --upgrade pip setuptools wheel
$python3 setup.py bdist_wheel

Derleme tamamlandığında ./dist/ dizininde oluşan wheel dosyasını sisteme kurarak işlemi sonlandırabilirsiniz:

$pip3 install dist/torchvision-*.whl
